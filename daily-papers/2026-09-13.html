AgentScope 1.0

📋 基本信息

  • 作者: Dawei Gao, Zitao Li, Yuexiang Xie 等
  • 机构: Alibaba Group
  • 链接: arXiv | PDF

🎯 研究动机与问题

现有 multi-agent 框架（如 LangChain, AutoGen）在以下方面存在不足： 1. 工具集成侵入性强：需要大量修改已有代码 2. 可观测性差：大规模部署时难以监控和调试 3. 长期记忆缺失：agent 无法保持跨会话的上下文 4. 分布式支持弱：难以扩展到大规模 multi-agent 场景

🔧 方法详解

核心架构

AgentScope 1.0 的核心抽象：

  1. MsgHub（消息总线）：agent 间消息传递的统一接口，支持广播和点对点通信
  2. StateModule（状态管理）：统一管理 agent 状态，支持序列化和恢复
  3. Non-Invasive Monitoring：基于 OpenTelemetry 的无侵入式监控

MCP 原生支持

原生集成 MCP（Model Context Protocol）协议： - Agent 可通过 MCP 协议访问外部工具和数据源 - 工具集成不需要修改 agent 代码（non-invasive） - 支持 MCP server 的自动发现和注册

分层记忆系统

  • InMemoryMemory：短期工作记忆，存储当前会话上下文
  • LongTermMemoryBase：长期记忆，支持跨会话信息持久化
  • 记忆检索支持语义搜索和结构化查询

ReAct Agent 内置实现

内置 ReAct 范式的 agent 实现： - Thought → Action → Observation 循环 - 支持自定义 tool 注册 - 内置错误处理和重试机制

分布式调度

  • 基于 gRPC 的分布式通信
  • 支持 agent 在多节点间调度
  • MsgHub 支持分布式消息广播

💡 核心贡献

  1. MCP 原生集成：首个原生支持 MCP 协议的 multi-agent 框架
  2. OpenTelemetry 可观测性：无侵入式监控，适合生产环境
  3. 分层记忆系统：短期 + 长期记忆，支持跨会话持久化
  4. 大规模部署经验：阿里内部大规模 multi-agent 部署验证

🤔 局限性与思考

  1. 框架评估困难：benchmark 上的数字不代表实际开发体验
  2. 与 LangChain 对比不够 fair：只挑了对方弱的场景
  3. 学习曲线：抽象层较多，新手上手成本可能较高
  4. MCP 生态尚未成熟：MCP 协议本身还在快速迭代

  • 作者: Baidu Inc.
  • 机构: Baidu Inc

  • 作者: Qinglin Zhang, Luyao Cheng, Chong Deng, Qian Chen, Wen Wang
  • 机构: Affiliation: , Affiliation: {qinglin.zql, shuli.cly, dengchong.d, tanqing.cq, w.wang}@alibaba-inc.com

10. Memanto: Typed Semantic Memory with Information-Theoretic Retrieval for Long-Horizon Agents

  • 作者: Seyed Moein Abtahi, Rasa Rahnema, Hetkumar Patel, Neel Patel, Majid Fekri, Tara Khani
  • 机构: Affiliation: , hetkumardineshbhai.patel@sheridancollege.ca
  • 链接: arXiv | PDF

  • 来源: 🔥 HF Trending，⬆️ 16

  • 核心方法: Memanto 生产级 agentic 记忆系统，用基于向量的架构实现零成本摄入，配 13 类语义分类的 typed memory schema + 集成冲突消解机制，明确不用知识图谱、不用多查询检索、不用 LLM 中介摄入。在 LongMemEval 和 LoCoMo 上做五阶段渐进式消融。

  • 对比方法/Baselines: 对标 graph-based 混合语义记忆架构（暗指 Zep 这类），突出自己摄入/检索开销更低。

  • 锐评: 敢在满屏知识图谱记忆里反着来，主打『不要 graph、不要 LLM 摄入、就纯向量 + 类型化 schema』，这份逆势的克制我欣赏——graph memory 的摄入成本确实劝退。13 类语义 schema 是它的赌注，赌得对就是优雅，赌错就是把 graph 的灵活性硬砍成硬编码分类。五阶段消融是加分项，说明作者知道要证明每个组件的必要性。只有 16 赞被埋了，但比很多百赞技术报告扎实。👀

Mem0

定义

一个开源的 AI 记忆层框架，为 LLM 应用提供持久化的用户/会话记忆管理，支持记忆的自动提取、存储、检索和更新。

核心要点

  1. 从对话中自动提取关键信息并存储为结构化记忆
  2. 支持多级记忆：用户级、会话级、Agent 级
  3. 基于向量检索实现相关记忆的上下文注入
  4. 与 Zep 等系统的区别：更轻量，侧重 key-value 式记忆而非图结构

相关概念

  • RAG
  • Episodic Memory
