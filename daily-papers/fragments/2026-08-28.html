1. When Memory Takes Gradients: Collaborative Vector Memory for Agentic Recommender Systems

  • 作者: Hanchong Chen, Xing Tang, Lingjie Li, Xiongfeng Shan, Xiuqiang He
  • 机构: Shenzhen Technology University
  • 链接: arXiv | PDF
  • 来源: 📄 arXiv 关键词检索
  • 核心方法: 指出现有 Agentic 推荐系统的用户记忆是 LLM 写出来的自然语言叙事，有两个硬伤：一次只能重写一条、更新成本高得离谱；协同信号（评分等）塞不进文本。CoVeMem 把记忆换成可求梯度的协同向量，能一次性吸收整段交互历史，并用 LightGCN 式协同证据补齐文本缺失的信息。

  • 锐评: 问题诊断非常精准——文本记忆更新成本和协同信号缺失确实是 agentic recsys 落不了地的两座大山。把记忆做成可求梯度的向量是自然但正确的解法。唯一悬念是：向量记忆一旦失去了文本的可解释性，agent 的『决策依据』还能不能审计？摘要没提冷启动和长尾用户表现。方向对，等看实验规模。🔥

  • 链接: arXiv | PDF

  • 来源: 📄 arXiv 关键词检索
