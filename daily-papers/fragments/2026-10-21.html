🔪 今日锐评

今天是 agentic 全家桶大乱斗：长程 agent 的信用分配（credit assignment）一天出了三篇，generative retrieval、LLM 路由、on-policy 蒸馏各有新活。最扎实的是那篇把 SID 设计自动进化的生成式检索工作和 NVIDIA 戳破 on-policy 蒸馏假设的分析型论文；最水的是一堆『把 agent 套到某个垂直领域』的 framework 论文。信用分配今天内卷到让人怀疑是不是同一个组投了三个会。

1. Evolving Semantic Indexes for Generative Retrieval

  • 作者: Jinming Nian, Jyun-Yu Jiang, Henry Tsai, Yi Fang, Zhirong Liang
  • 机构: Email: , Email: henrytsai@haas.executivealumni.berkeley.edu, Affiliation: Santa Clara University, Affiliation: 
  • 链接: arXiv | PDF
  • 来源: 📄 arXiv 关键词检索
  • 核心方法: 把生成式检索（GR）里一直靠手工拍脑袋的语义 ID（SID）设计——构造、碰撞处理、解码、训练四个互相耦合又不可微的组件——交给一个 LLM 驱动的进化搜索 EVOLVE 去自动优化。核心是把离散、相互依赖、无法端到端梯度优化的设计空间，用 block-wise 的进化/搜索框架探索，在 NQ 等检索基准上对比 TIGER 等手工 SID。
  • 对比方法/Baselines: TIGER（手工 SID 的代表）、标准 GR 管线、SEARCH 相关基线
  • 借鉴意义: 直接打在 recsys/生成式检索的命门上：所有人都知道 SID 设计决定 GR 上限，但没人能端到端优化它。能自动搜索出更好的 SID，对工业级 generative recommendation 是真·降本提效。
  • 锐评: 终于有人不装了——承认 SID 设计就是 GR 的玄学，然后真去自动化它。切入点精准，四个不可微组件的拆解很到位。唯一担心：进化搜索的计算开销和 SID 空间爆炸，论文最好给出搜索成本 vs 收益曲线，否则就是『用 100 倍算力换 2% recall』的老套路。摘要没提搜索预算，存疑。🔥

2. Self-Credit: Credit Assignment for Long-Horizon Agentic RL via Intra-group Rescaling

  • 作者: Fangcong Yin, Ming Yin, Tanvi Bhandarkar, Aashu Singh, Eryk Helenowski, Shlok Kumar Mishra, Saghar Hosseini, Karthik Abinav Sankararaman, Greg Durrett, Dinkar Juyal
  • 机构: Affiliation: New York University, Affiliation: Duke University, Affiliation: 
  • 链接: arXiv | PDF

  • 来源: 📄 arXiv 关键词检索

  • 核心方法: Self-Credit 针对 RLVR 奖励稀疏、长程任务信用分配难的问题，用自生成的信用分配在 group-based RL（GRPO 家族）内部做 intra-group rescaling，把稀疏的 outcome reward 变成 dense 监督信号。三个组件搭在组内相对比较上，在 BrowseComp、GAIA 等 deep search 基准测。

  • 对比方法/Baselines: GRPO、GiGPO、ECHO
  • 借鉴意义: 长程 agent 训练（deep search、多轮 tool use）的核心瓶颈就是稀疏奖励下的信用分配，和推荐里的延迟/稀疏反馈问题同构，方法可迁移。
  • 锐评: intra-group rescaling 的思路干净，不引入额外 reward model 这点加分（省钱）。但今天 FALCA、TrajEvolve、Self-Credit 三篇都在做长程信用分配，彼此几乎不引用对方，强烈怀疑是同一波人卷同一个坑。想看谁真的 SOTA 得把三篇放一起 benchmark，现在各说各话。👀

3. Capable Teacher, Myopic Scorer: Reward-Free Teacher Repair for Agentic On-Policy Distillation

  • 作者: Shu Zhao, Tan Yu
  • 机构: Email: , Affiliation: NVIDIA, Affiliation: 
  • 链接: arXiv | PDF

  • 来源: 📄 arXiv 关键词检索

  • 核心方法: TCOD（Capable Teacher, Myopic Scorer）质疑 agentic on-policy 蒸馏（OPD）里流行的 compounding error 叙事：主流方法假设学生跑偏后会离开 teacher 可靠区域，于是用 episode 课程、teacher 引导轮次把训练限制在该区域内。这篇提出 reward-free 的 teacher repair，直接修复 teacher 打分短视的问题，在 WebShop、ScienceWorld 上对比 TCOD-F2B、FutureBridge。

  • 借鉴意义: on-policy 蒸馏是训练小 agent 的主流路线，推翻『compounding error 是主因』的共识会改变整个蒸馏课程设计思路。
  • 锐评: NVIDIA 出手，观点锋利——不跟着『把训练困在 teacher 舒适区』的叙事走，而是说问题出在 teacher 自己打分短视（myopic scorer）。这种挑战共识的分析型论文比又一个 framework 有价值得多。标题起得也好。扣分项：reward-free repair 的泛化边界要看实验，别只在两个 toy 环境上成立。👀

4. FALCA: Falsification-Aware Reinforcement Learning with Hierarchical Credit Assignment for Long-Horizon Deep Search Agents

  • 作者: Zijun Dou, Kun Luo, Chaofan Li, Shuqi Lu, Zheng Liu\corresponding
  • 机构: royz.dou,luokun695,zhengliu1026@gmail.com
  • 链接: arXiv | PDF
  • 来源: 📄 arXiv 关键词检索
  • 核心方法: FALCA 给 long-horizon deep search agent 做『证伪感知』+分层信用分配：针对 agent 早期错误（锚定错误候选、收集部分支持证据、忽略矛盾）沿轨迹被放大的问题，用 falsification-aware 的 RL 在多层级做 credit assignment，基于 ReAct/IRCoT 式的推理-检索交织。在 BrowseComp、GAIA、WideSearch 上测。

6. MemT-1.0: Towards Memory-Native Evolution

  • 作者: MemTensor Team
  • 链接: arXiv | PDF
  • 来源: 🔥 HF Trending，⬆️ 147
  • 核心方法: MemT-1.0 把记忆做成基础模型的原生能力（memory-native），不靠外挂检索。基于 Metis，用 Gated DeltaNet-2 在每一轮内做稳定的 token 级记忆更新；每个选中的 Transformer block 加一个 native memory block，并行跑原始注意力和记忆注意力，含动态局部记忆 + 可训练 hyper memory，配 native 的存取流程。在 LoCoMo 上测，涉及 CPT/LoRA/KD 训练。

7. COMPASS: Routing via Capability-Oriented Model Profiling with Adaptive Search, Selection, and Tool Use

  • 作者: Amin Rezaei
  • 机构: University of Minnesota
  • 链接: arXiv | PDF

  • 来源: 📄 arXiv 关键词检索

  • 核心方法: COMPASS 把 LLM 路由从『训练一个专用 router』改成 agentic：LLM 跟着一份 routing recipe，用工具去收集各候选模型的性能和成本证据，必要时先看候选答案再选模型，避免模型/任务变化时 router 需要重训。在 TerminalBench 等上对比 Avengers-Pro、FrugalGPT。

  • 对比方法/Baselines: FrugalGPT、Avengers-Pro、one-step trainable routers
  • 借鉴意义: 模型路由是降本核心（贵模型只在该用时用），把它 agentic 化解决了 router 随模型迭代就失效的痛点，工程价值明确。
  • 锐评: 痛点抓得准——专用 router 确实一换模型就废。用 agent 动态查证据选模型，优雅但贵：每次路由都要额外的工具调用和候选答案 inspection，省下的钱可能被路由本身的开销吃掉。关键看它给没给『路由开销 vs 节省成本』的净收益账，没有的话就是拆东墙补西墙。👀

  • 机构: Affiliation: University of Pennsylvania, Affiliation:

  • 核心方法: 测试多 agent 协作（MAS）在『agent 服务用户』的 dual-control 设定下还值不值。既有结论（Kim et al. 2026）给出 capability-saturation 规则：单 agent 弱时协作有益、强到约 45% 准确率后协作反而有害。但那是在无用户参与的 autonomous 基准上得出的。本文在有用户介入的双控设定下重测 SAS vs MAS 的 scaling。
