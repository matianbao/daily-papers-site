1. FSGR: Mitigating Token Frequency Bias for Fair SID-Based Generative Recommendation

  • 作者: Yuchen Zheng, Sihan Xu, Jingwen Yang, Xiangrui Cai \corresponding, Haiwei Zhang, Xiaojie Yuan
  • 机构: FSGR: Mitigating Token Frequency Bias for Fair SID-Based Generative Recommendation
  • 链接: arXiv | PDF
  • 来源: 📄 arXiv 关键词检索
  • 核心方法: 指出 SID-based 生成式推荐存在被前人忽视的 Token Frequency Bias：高频 SID token 被系统性过度预测、低频 token 被压制，本质是 Semantic ID 分词后的频率长尾在 decoder 里被放大。FSGR 从公平性角度切入去纠偏，让长尾 item 的召回不被高频 token 吞掉。
  • 对比方法/Baselines: 对比标准 SID 生成式推荐（TIGER 类范式），涉及 RQ/BSQ 量化码本与 HFC 频率校准。
  • 借鉴意义: 这是你核心战场——生成式推荐里 semantic ID 的频率偏差直接影响长尾变现和多样性，比又一篇 LLM4Rec 套壳有价值得多。
  • 锐评: 终于有人认真处理 SID 的频率长尾而不是继续吹 scaling。把它定义成「公平性」问题稍微用力过猛（本质就是分布偏移+曝光偏差），但诊断和缓解都落到了实处。唯一悬念：纠偏后 head item 的精度掉多少？摘要没给 trade-off 曲线，得看正文。🔥

3. StateBridge: Training-free Hidden-state Alignment for Latent Communication in LLM Multi-Agent Systems
