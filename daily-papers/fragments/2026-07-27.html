4. Multi-Head Latent Control: A Unified Interface for LLM Agent Decision Making

  • 作者: Ghasemabadi, Amirhosein, Chen, Ruichen, Rashidi, Bahador, Niu, Di
  • 机构: 2Huawei Technologies Canada Co., Ltd, 1ECE Department, University of Alberta

5. GEPA: Reflective Prompt Evolution Can Outperform Reinforcement Learning

  • 作者: Agrawal, Lakshya A, Tan, Shangyin, Soylu, Dilara, Ziems, Noah, Khare, Rishi, Opsahl-Ong, Krista, Singhvi, Arnav, Shandilya, Herumb, Ryan, Michael J, Jiang, Meng, Potts, Christopher, Sen, Koushik, Dimakis, Alexandros G., Stoica, Ion, Klein, Dan, Zaharia, Matei, Khattab, Omar
  • 机构: Stanford, UC Berkeley
  • 链接: arXiv | PDF

  • 来源: 🔥 HF Trending，⬆️ 34

  • 核心方法: GEPA（Reflective Prompt Evolution）主张语言本身是比标量 reward 更丰富的学习介质：让 LLM 反思自己的执行轨迹（自然语言反馈），迭代进化 prompt，而不是靠 GRPO 那种从稀疏标量 reward 推出的 policy gradient。声称只用少量 rollout 就能超过跑上千次 rollout 的 RL。

  • 对比方法/Baselines: 直接对标 GRPO 等 RL 方法，以及 prompt 自动调优路线（后续 SkillOpt 引用了它）。
  • 借鉴意义: 如果结论站得住，对做 LLM agent 任务适配的人是范式级提示：先榨干可解释的语言反馈，再考虑上 RL。省算力、省时间。
  • 锐评: Stanford + Berkeley 的豪华作者阵容（Zaharia、Klein、Potts、Khattab、Stoica 全在），DSPy 一脉相承。『可解释语言比标量 reward 信息量大』这个论点本身很性感，但要小心：能被 prompt 反思解决的任务，往往本来就没到 RL 该出场的难度——拿这类任务证明『反思 > RL』有点田忌赛马的味道。任务范围是关键，得看它在真正需要探索的任务上还灵不灵。🔥

6. Molt: A Scalable PyTorch-Native Training Framework for Agentic Reinforcement Learning

  • 作者: Jian Hu, Huiying Li, Hao Zhang, Binfeng Xu, Yifan Zhang, Shaokun Zhang, Hemil Desai, Michael Demoret, Pavlo Molchanov, Jan Kautz, Yi Dong NVIDIA {jianh,yidong}@nvidia.com
  • 机构: NVIDIA, {jianh,yidong}@nvidia.com
  • 链接: arXiv | PDF
  • 来源: 📰 HF Daily，⬆️ 10
  • 核心方法: Molt 是 NVIDIA 的 PyTorch-native agentic RL 训练框架。核心论点：agentic RL 研究的真正成本在于算法频繁改动时，改动要穿透 trainer / 分布式后端 / rollout glue 层层耦合。Molt 通过组合各自在 frontier scale 已被硬化的组件，让 scalability 是『继承』来的而非重造，同时保持代码可读。
  • 对比方法/Baselines: 对标主流 agentic RL 框架（如 verl 等）在算法迭代时的高改动成本。

  • 锐评: NVIDIA 出手，把痛点定位在『regime mismatch：超大规模栈是为最大 job 优化的，而研究迭代是为算法改动速率优化的』——这个 framing 相当精准，戳中了所有被框架 glue code 折磨过的 RL researcher。风险在于『组合已硬化组件就能继承 scalability』这句话太理想，组件边界处的性能和正确性往往才是魔鬼。得看真实大规模跑起来会不会漏。👀

7. SkillOpt: Executive Strategy for Self-Evolving Agent Skills

  • 作者: Yang, Yifan, Gong, Ziyang, Huang, Weiquan, Yang, Qihao, Zhou, Ziwei, Huang, Zisu, Li, Yan, Gao, Xuemei, Dai, Qi, Liu, Bei, Qiu, Kai, Yang, Yuqing, Chen, Dongdong, Yang, Xue, Luo, Chong
  • 机构: Fudan University, Microsoft, Shanghai Jiao Tong University, Tongji University
  • 链接: arXiv | PDF
  • 来源: 🔥 HF Trending，⬆️ 262
  • 核心方法: SkillOpt 主张 agent skill 应像深度学习 optimizer 优化权重一样被『训练』：把 skill 当作 frozen agent 的外部状态，用同样的纪律（可复现、在反馈下可靠改进）来演化它，而非手写、一次性生成或松散的自我修订。
  • 对比方法/Baselines: 对标 GEPA（trajectory 反馈驱动 prompt 进化）、TextGrad、EvoSkill、ABSTRAL、EvoTest。
  • 借鉴意义: 对做自演化 agent、想让 skill 在反馈下稳定变强的人，『skill 即外部可训练状态』的类比给了清晰的优化框架。
  • 锐评: 复旦 + 微软 + 上交 + 同济，262 赞冲上榜首级别热度。核心 insight——『把 skill 当作 frozen agent 的外部状态，用 weight-space 优化的纪律去训练它』——是对 GEPA 那条线的漂亮升维，且诚实点出现有方法『none reliably improves over its starting point』的通病。质疑点：weight-space 优化的可复现性靠梯度和确定性，而 skill 空间是离散、语言、非平滑的，硬套 optimizer 的『纪律』能不能真的稳定收敛，还得看实验的方差。🔥
