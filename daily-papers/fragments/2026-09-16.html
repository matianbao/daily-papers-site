5. Large Language Models Develop Belief State Geometry In-Context

  • 作者: Balcells, Daniel, Lee, Andrew Jun, Rastogi, Chirag, Riechers, Paul M., Shai, Adam, Poncini, Xavier
  • 机构: Astera Institute
  • 链接: arXiv | PDF

  • 来源: 📄 arXiv 关键词检索

  • 核心方法: Belief-State-Geometry 在受控设置下研究 ICL 的表征：用隐马尔可夫模型（HMM）生成的数据 prompt LLM，然后探针检测模型内部是否表征了 belief state——即给定观测 token 历史后，对 HMM 隐藏状态的后验分布。

  • 对比方法/Baselines: 线性/非线性探针在 HMM 后验几何上的拟合。
  • 借鉴意义: 对理解 ICL 本质是重要一步：如果 LLM 真的在内部维护贝叶斯信念更新，那 ICL 就不只是模式匹配，而是隐式的贝叶斯推断。
  • 锐评: Astera Institute 出品，罕见的做正经科学而非刷榜的工作。用 HMM 做 ground-truth 后验、再探针验证 belief state geometry，实验设计干净、可证伪。这类机制可解释性研究比又一篇 agent 框架有长期价值得多。唯一遗憾：HMM 太玩具，真实语言的 belief state 会不会同样干净是个大问号。🔥
