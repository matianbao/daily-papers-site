1. It Takes Two to Match: Co-Evolving Generative Retriever with Reinforcement Learning

  • 作者: Runpeng Dai, Kaili Huang, Changsung Kang, Ciya Liao
  • 机构: Ciya Liao: ciya.liao@apple.com, Affiliation: 1University of North Carolina at Chapel Hill  2Apple, Affiliation:
  • 链接: arXiv | PDF

  • 来源: 📰 HF Daily，⬆️ 54

  • 核心方法: CoGR（Co-Evolving Generative Retriever）针对搜索/广告召回的第一阶段，指出现有工作只把 LLM 用在 query 侧扩展/数据合成，最终匹配还是甩给下游 retriever。CoGR 让生成器和检索器通过 RL（GRPO）协同进化——生成侧不只是改写 query，而是直接参与匹配闭环，用检索反馈训练生成。对比 SFT 单向蒸馏，形成双向 co-evolution。

  • 对比方法/Baselines: ANCE、DSI（可微搜索索引）、纯 SFT 基线，数据集用 WANDS（商品检索）。
  • 借鉴意义: 直接命中你最关心的「generative retrieval + 广告/搜索召回」。生成器参与最终匹配而非只做 query 侧增强，这个思路对召回粗排链路的重构有实打实的借鉴价值，而且是 Apple 工业团队做的，54 个 upvote 不是白来的。
  • 锐评: 标题「It Takes Two to Match」有点营销腔，但内核是硬的：把生成式检索从「query 侧花活」拉回到「参与匹配的一等公民」，用 RL 闭环把生成器和检索器绑一起训。真正的问题是——co-evolution 的训练稳定性和线上召回延迟摘要里没细说，工业落地这两点才是生死线。但方向对，值得精读。🔥

2. DMRL: Document-Mediated Reinforcement Learning for Skill Optimization in Advertising Recommendation

  • 作者: Wei Zhang, Hongji Li, Song Sun, Peng Yu, Xue Yang, Lei Zhao, Peng Jiang
  • 机构: 1]Shanghai Jiao Tong University, \setsjtublue\settitlerulethickness3pt \abstractboxon\setabstractframecolorgray \setabstractbgcolorgray!10 \setlogotolineshift5mm \settoprulethickness2.5pt, Affiliation:
  • 链接: arXiv | PDF
  • 来源: 📄 arXiv 关键词检索
  • 核心方法: DMRL（Document-Mediated RL）解决广告推荐里「用 LLM + 技能文档调参」的归因难题：现有做法是 prompt-driven 地改技能文档，但没法把奖励归因到具体的文档编辑。DMRL 用 GRPO 类方法（提出 DRPO）把每次文档 edit 当作可归因的动作，联合优化 LTV/商业回报与用户体验（ST/LT 短长期指标）。

  • 锐评: 这篇是今天对广告工业最对口的一篇。把「改 prompt/技能文档」从玄学变成可归因的 RL 动作，思路干净。但我要泼冷水：广告系统里长短期指标（ST/LT）本身就充满 confounder，用离线归因去分配 reward 到单条文档编辑，很容易学到「相关不等于因果」的假信号——摘要没给因果隔离的实验设计，这是我最想拷问的点。方向强推，结论保留。👀

4. APEx: Distillation of Agent Procedural Experience for Adaptive Deep Research Question Answering

  • 作者: Jie Ding, Rui Sun11footnotemark:, Xinyuan Zhang, Zeyu Zhang, Xin Liu
  • 机构: Affiliation: Chinese Academy of Sciences, Affiliation: ByteDance Inc.{jieding25,rrsun}@mail.ustc.edu.cn, xliu@gia.cas.cn, Affiliation: University of Science and Technology of China, Affiliation: 
  • 链接: arXiv | PDF
  • 来源: 📄 arXiv 关键词检索
  • 核心方法: APEx（Agent Procedural Experience distillation）针对 deep research agent：现有经验学习要么检索冗长的 task-specific 轨迹拖累决策，要么蒸馏的技能与下游策略脱节。APEx 分两级——instance-level 保留具体执行轨迹，category-level 蒸馏跨任务可复用技能，并用 TTRL（test-time RL）+ GRPO 把技能与策略适配耦合起来。

5. Belief-Calibrated Optimization: An Explicit World Model for Agentic Optimization

  • 作者: Yuhan Chen, Zhihua Tian, Mahavir Dabas, Charith Peris, Rahul Gupta, Ming Jin, Feiyang Kang, Siyuan Zhang, Nan Wang, Ruoxi Jia
  • 机构: Amazon
  • 链接: arXiv | PDF
  • 来源: 📄 arXiv 关键词检索
  • 核心方法: Belief-Calibrated Optimization 观察到：用 coding agent 当 optimizer 迭代改进 scaffold 时，每次编辑背后都有个「关于环境会如何响应」的信念，但这个信念通常是隐式的。本文把它显式化成一个 world model，区分 execution beliefs（编辑如何影响 agent 行为）和 evaluation beliefs，用它校准优化方向。
  • 对比方法/Baselines: coding-agent-as-optimizer 基线；测于 GAIA、Terminal-Bench、AppWorld、LongMemEval、LoCoMo。
  • 借鉴意义: 把 agent 自我优化里的隐式假设显式建模，是「让优化可解释、可纠偏」的正确方向，对做 agent scaffold 自动迭代（类似 auto-train 场景）有方法论价值。
  • 锐评: 这篇有点意思：它没有再造一个新 agent，而是去追问「优化器每次改代码时脑子里那个隐式假设是什么」，然后把它拎出来做成显式世界模型。这是元层面的清醒——大多数 agent-as-optimizer 工作都在盲改。Amazon 出品，benchmark 铺得很全（GAIA/Terminal-Bench/AppWorld 都是硬骨头）。风险是显式信念建模本身引入的复杂度，会不会得不偿失。方向新颖，👀。

6. PGPO: Potential-Guided Policy Optimization for Multi-Turn Agentic Tasks

  • 作者: Zheng, Yuyao, Sun, Haipeng, Bao, Junwei, Liu, Lemao, Jiang, Hongfei, Song, Yang, Dou, Dejing
  • 机构: Fudan University
  • 链接: arXiv | PDF

  • 来源: 📄 arXiv 关键词检索

  • 核心方法: PGPO（Potential-Guided Policy Optimization）解决 group-based RL 在多轮 agentic 任务里「稀疏终局奖励导致中间动作信用粗糙」的问题。指出 GiGPO 虽引入 step-level advantage，但仍依赖单条轨迹的最终结果。PGPO 引入势函数（potential）来做更细粒度、跨轨迹的信用分配。

  • 对比方法/Baselines: GiGPO 及 group-based RL（GRPO 系）多轮基线。
  • 借鉴意义: agentic RL 的信用分配是所有多步 agent 训练的通用瓶颈，势函数塑形是经典 RL 理论（potential-based reward shaping 有理论保证），用到 LLM agent 上是对的方向。
  • 锐评: 把经典的 potential-based reward shaping 搬到 LLM 多轮 agent 的信用分配，理论根基比一堆拍脑袋的 heuristic step-reward 靠谱多了——势函数塑形不改变最优策略这个性质是有保证的。可惜 filtered 数据里 method_names 只剩 TeX/CSS（抽取翻车了），得看正文确认它是否真沿用了势函数的不变性保证。方向扎实，👀。

7. Cliff: Learning Process Rewards from the First Mistake

  • 作者: Peixuan Han, Runhui Wang, Ketan Ramaneti, Jie Hao, Gerald Friedland, Chris Kong
  • 机构: Affiliation: University of Illinois Urbana-Champaign, Affiliation: Amazon Web Services, Affiliation: 
  • 链接: arXiv | PDF
  • 来源: 📰 HF Daily，⬆️ 15
  • 核心方法: Cliff（Learning Process Rewards from the First Mistake）针对 RLVR 只有粗粒度 outcome reward、对中间推理指导不足的问题。核心洞察是从「第一个出错的步骤」学过程奖励（FIRST），避免额外训练专门的过程奖励模型（PRM）或依赖 on-policy 蒸馏（OPD）的重约束。
  • 对比方法/Baselines: GRPO、DAPO、过程奖励建模、on-policy distillation，测于 MATH-500。
  • 借鉴意义: 过程奖励是当前 reasoning RL 的核心议题，「从第一个错误定位学信号」这个切入点比训一个笨重 PRM 轻量，对做推理模型后训练有直接参考。
  • 锐评: 「从第一个错误学过程奖励」这个 framing 我喜欢——它承认了一个朴素事实：一条推理链一旦第一步错了后面全是噪声，那奖励信号就该锚在断裂点。比动辄训个 PRM 优雅。HF 15 upvote 说明社区认。但「第一个错误」怎么无监督地精确定位？如果定位本身要靠另一个模型，那不过是把 PRM 的活换了个马甲。得看它怎么闭环。👀

11. CHIME: Credit-Aware Hierarchical Memory Evolution for Long-Horizon Agentic Planning

  • 作者: Yongshi Ye, Tian Lan, Feihu Jiang, Muyang Ye, Bin Zhu, Qianghuai Jia, Longyue Wang\corresponding, Zhao Xu, Weihua Luo, Xiaodong Shi\corresponding
  • 机构: Alibaba Group, Institute of Artificial Intelligence, Xiamen University, Key Laboratory of Digital Protection and Intelligent Processing of Intangible Cultural Heritage, Zhejiang University, author: wanglongyue.wly@alibabainc.com, of Fujian and Taiwan (Xiamen University), Ministry of Culture and Tourism
  • 链接: arXiv | PDF
  • 来源: 📄 arXiv 关键词检索
  • 核心方法: CHIME（Credit-Aware Hierarchical Memory Evolution）属于 self-evolving memory 路线：冻结模型参数，只更新外部记忆库，把交互轨迹蒸馏成可复用经验来提升长程规划。相比 ReasoningBank 等，CHIME 加了「信用感知」的分层记忆进化机制，区分不同记忆条目对结果的贡献。

12. Codebook Agent: Amortized Topology Design for LLM Multi-Agent Systems

  • 作者: Jinxi Yu, Yubei Li, Eric Hanchen Jiang, Zhi Zhang, Dong Liu
  • 机构: Affiliation: 
  • 链接: arXiv | PDF
  • 来源: 📄 arXiv 关键词检索
  • 核心方法: Codebook-Agent（Amortized Topology Design）批评现有多智能体拓扑设计把问题当作条件图生成——用 VAE/自回归/扩散 decoder 在 N×N 邻接空间搜索，再用图网络代理排序，太重。改为用一个「码本」（codebook）摊销拓扑设计：预学一组拓扑原型，query 时检索/组合而非从头生成。

11. CHIME: Credit-Aware Hierarchical Memory Evolution for Long-Horizon Agentic Planning

  • 作者: Yongshi Ye, Tian Lan, Feihu Jiang, Muyang Ye, Bin Zhu, Qianghuai Jia, Longyue Wang\corresponding, Zhao Xu, Weihua Luo, Xiaodong Shi\corresponding

12. Codebook Agent: Amortized Topology Design for LLM Multi-Agent Systems

  • 作者: Jinxi Yu, Yubei Li, Eric Hanchen Jiang, Zhi Zhang, Dong Liu
  • 机构: Affiliation: 
  • 链接: arXiv | PDF
  • 来源: 📄 arXiv 关键词检索
  • 核心方法: Codebook-Agent（Amortized Topology Design）批评现有多智能体拓扑设计把问题当作条件图生成——用 VAE/自回归/扩散 decoder 在 N×N 邻接空间搜索，再用图网络代理排序，太重。改为用一个「码本」（codebook）摊销拓扑设计：预学一组拓扑原型，query 时检索/组合而非从头生成。
  • 对比方法/Baselines: GPTSwarm、DyLAN 等拓扑优化方法；测于 HumanEval、MATH、MMLU、MBPP、MultiArith。
  • 借鉴意义: 多智能体系统的通信拓扑决定成本和精度，把它从「每次现搜」变成「码本摊销」能大幅降低设计开销，对做多 agent 编排的成本控制有价值。
  • 锐评: 思路很对：多智能体拓扑设计根本不需要每个 query 都跑一遍扩散 decoder 去 N×N 空间里瞎搜，那是 GPTSwarm 时代的奢侈。用码本把常见拓扑摊销掉，检索组合就行——这是把「学结构」降维成「查结构」，工程上性价比高。风险是码本的表达力上限：真遇到码本没覆盖的怪异任务拓扑，退化成什么样？摘要没说 OOD 表现。多 agent 方向里今天最实用的一篇。👀

15. SCX Router: Streaming Zero-Shot Model Selection with a Decoder-KV Classifier and a Real-World Task Ontology

  • 作者: Ihor Stepanov, Aleksandr Smechov, Mykhailo Shtopko, Dmytro Vodianytskyi, Oleksandr Lukashov
  • 机构: Affiliation: 
  • 链接: arXiv | PDF
  • 来源: 📄 arXiv 关键词检索
  • 核心方法: SCX-Router 做流式零样本模型选择：用一个 decoder-KV 分类器 + 真实任务本体（ontology），在 speed/cost/quality 上做 per-task 的模型选择，无需为路由重新训练。
