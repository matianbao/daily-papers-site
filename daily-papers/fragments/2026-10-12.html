1. Beyond Semantic IDs: Finite-Beam Reachability and Continuous-Query Generation in Generative Recommendation

  • 机构: moved to a language-style generator that is trained to emit the SID sequence. Larger pretrained language
  • 链接: arXiv | PDF

  • 来源: 📄 arXiv 关键词检索

  • 核心方法: 正面拷问 生成式推荐（GR）的输出接口：用有限宽度 beam search 自回归解码 Semantic ID（SID）时，held-out target 到底有多大概率进不了返回列表。论文区分了「全库可打分性」（catalog-wide scoreability）和「经验 top-K 支持度」，并提出 CQG（Continuous-Query Generation）绕开离散 SID 的 beam 瓶颈。

3. Rollout-Time Intervention: Unlocking Agentic Reinforcement Learning Beyond Policy Limits

  • 机构: Affiliation: Alibaba Token Hub, Alibaba Group, Affiliation: , Affiliation: HKUST (Guangzhou), Affiliation: Amap, Alibaba Group

  • 来源: 📄 arXiv 关键词检索
  • 核心方法: 提出 RTI（Rollout-Time Intervention）解决 agentic RL 的「on-policy 推理瓶颈」：当任务超出模型当前能力边界时，有效轨迹极度稀疏导致训练崩溃。RTI 在 rollout 阶段注入干预，让 agent 能产出超出自身策略极限的轨迹来学习，基于 GRPO 框架。

17. ResearchStudio-Idea: An Evidence-Grounded Research-Ideation Skill Suite from ML Conference Outcomes

  • 作者: Qihao Zhao1
  • 机构: Microsoft Research, Nanyang Technological University, National University of Singapore
  • 链接: arXiv | PDF
  • 来源: 🔥 HF Trending，⬆️ 63
  • 核心方法: IdeaSpark/ResearchStudio-Idea 把研究选题的「第一英里」做成可复用的 skill 套件：从 ML 会议的真实 outcome 数据里学习，帮研究者把问题扎根于文献、识别瓶颈、与现有方案区分、评估风险。用 HDBSCAN 聚类等。
  • 对比方法/Baselines: 对标端到端研究自动化系统、多智能体/检索增强的 ideation 工具、新颖性检测工具。
  • 借鉴意义: LLM 辅助科研选题，HF 63 赞说明研究者社区有真需求，但与你的核心领域（推荐/广告）相关性弱。
  • 锐评: HF 63 赞，社区显然对「帮我想选题」有刚需——毕竟灌水都想灌得有的放矢。从真实会议 outcome 学习这点比凭空生成 idea 靠谱。但「研究 ideation skill 套件」本质是个精致的文献检索+聚类+prompt 工程组合，别把它神化成能替你做研究品味。和你的工作线关系不大。🫠

18. Agent4Spec: An LLM-based Agentic System to Optimize API Specifications through Automated Validation and Market Analysis

  • 作者: Tang, Yongjian, Moraru, Costel, Tuncel, Doruk, Elhashemy, Hanya, Klepke, Steffen, Runkler, Thomas
  • 机构: Affiliation: , 2Technical University of Munich, Munich, Germany
  • 链接: arXiv | PDF
  • 来源: 📄 arXiv 关键词检索
  • 核心方法: Agent4Spec 用 LLM 多智能体系统持续优化 API 规范（OpenAPI/OAS）：把「从源码生成初始规范」从一次性事件变成持续验证+长期维护，含 OrchestratorAgent、SpecificationGenerationAgent 等角色，还做 Market Analysis。
  • 对比方法/Baselines: 对标把 spec 生成当一次性任务的 LLM 方法，用 Claude-Sonnet/GPT-5 做骨架。
  • 借鉴意义: API 规范自动维护是具体的工程问题，但场景偏窄，与推荐/广告/LLM 核心方向关联弱。
  • 锐评: 把 API spec 从「生成一次就扔」变成「持续验证维护」的角度不错，戳中了真实工程痛点。但场景太垂直——它解决的是软件工程团队的 API 文档问题，离你关注的东西隔着好几个部门。再加个「Market Analysis」agent 多少有点为了多智能体而多智能体。🫠

  • 机构: Affiliation: Yonsei University, Affiliation:

21. Humanize MLE Agents: Multi-Agent Session Alternation Beyond Single-Agent Limits

  • 作者: Changye Li, Zijian Zhang, Muheng Li, Yiduo Pang, Tingjun Wu, Menghan Li, Yitong Liu, Hongkai Guo, Mengchi Chen, Chenyu He, Kaisheng Ma, Wei Xu, Song Han, Sihao Liu, Ligeng Zhu
  • 机构: Affiliation: NVIDIA, Affiliation: Tsinghua University, Affiliation: , Affiliation:  Zhejiang University
  • 链接: arXiv | PDF

  • 来源: 📄 arXiv 关键词检索

  • 核心方法: HMA（Humanize MLE Agents）发现长程机器学习工程（MLE）agent 的「长程减速」现象：单会话越长，agent 推理强度越低、进度越慢（响应 token 数从 0-2 小时到 3-5 小时降 29.8%-45%）。方案是多智能体会话轮换，突破单 agent 极限。

  • 对比方法/Baselines: 对标定制 harness 的单会话 MLE agent，在 MLE-bench 子集上用 DeepSeek-V4 系列测 medal rate。
  • 借鉴意义: 「长会话 agent 会变懒」是个有意思的实证观察，对做长程 agent 的有警示价值。
  • 锐评: 最有价值的是那个实证发现——agent 单会话跑久了响应会缩水 30-45%，这个「长程减速」现象本身比它的解法更值得记住。解法（多会话轮换「刷新」agent）有点像给员工强制下班再上班，trick 味重于洞见。NVIDIA+清华阵容，观察扎实，方案普通。🫠

22. Stride: Scale-Aware Multi-Agent Evolutionary Refinement for Infographic Generation

  • 作者: Yan Zhou, Yang Yang
  • 机构: Email: , Email: angelayang@sjtu.edu.cn, Email: yanzhougemzhou@sjtu.edu.cn, Affiliation: School of Artificial Intelligence, Affiliation: Shanghai Jiao Tong University, Affiliation: 
  • 链接: arXiv | PDF

  • 来源: 📄 arXiv 关键词检索

  • 核心方法: Stride 做信息图（infographic）生成的多智能体进化式精炼：单图要同时满足视觉/文本/语义多重约束，局部编辑改不了全局构图错误、整图重生又会毁掉已对的区域。Stride 用「尺度感知」（scale-aware）的多智能体进化精炼，配多模态 verifier 在不同尺度上改。

  • 对比方法/Baselines: 对标迭代式 agentic 精炼 + 多模态 verifier 的现有方法，在 BizGenEval 等评测。
  • 借鉴意义: 信息图生成是 text-to-image 的硬骨头（文字+布局+语义），scale-aware 的 local/global 平衡思路可借鉴到多模态生成。
  • 锐评: 点中了 text-to-image 做信息图的死穴——局部改不动全局、全局改又毁局部，这个「尺度错配」问题提得准。多尺度进化精炼是合理的解法方向。但「多智能体 + 进化 + verifier」三件套堆在一起，复杂度高、推理成本大，实用性存疑，更像 benchmark 导向的研究。离你的核心领域较远。🫠

  • 机构: Aske Plaat, Max van Duijn, Michiel van der Meer, Niki van Stein
