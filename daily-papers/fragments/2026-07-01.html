3. TRIAGE: Role-Typed Credit Assignment for Agentic Reinforcement Learning

  • 作者: Yuanda Xu1
  • 机构: 1LinkedIn Corporation  2Harvard University  3Johns Hopkins University
  • 链接: arXiv | PDF
  • 来源: 📄 arXiv 关键词检索
  • 核心方法: 针对 agentic RL 的信用分配。标准 GRPO 用最终 verifier 结果 $r_i=V(\tau_i)\in{0,1}$ 做组归一化优势 $A_i=(r_i-\bar r)/(\sigma_r+\epsilon)$，均匀分给轨迹里每个 token——结构性缺陷是：失败 rollout 里的有益探索被惩罚，成功 rollout 里的冗余/倒退动作被强化。TRIAGE 按动作角色分型（搜索、点击、编辑、导航等 environment-facing action）做差异化信用分配。
  • 对比方法/Baselines: 直接对标 GRPO，在 WebShop、QA 等 agentic 环境上评估。
  • 借鉴意义: GRPO 的 uniform advantage 是当前 agentic RL 训练最被诟病的点，角色分型信用分配是很自然但少人系统做的方向。做 agent 训练/RLHF 的必读。
  • 锐评: 诊断一针见血：uniform advantage 在长程 agent 轨迹里就是灾难，好探索被埋、坏动作被夸。角色分型（role-typed）的切入点比那些堆 reward model 的方案干净。隐忧是「动作角色」怎么自动划分、跨环境泛化如何——如果需要人工定义每类动作的 credit 规则，那实用性就打折。LinkedIn+Harvard+JHU 的组合，工程味应该够。🔥

3. TRIAGE: Role-Typed Credit Assignment for Agentic Reinforcement Learning

  • 作者: Yuanda Xu1
  • 机构: 1LinkedIn Corporation  2Harvard University  3Johns Hopkins University
  • 链接: arXiv | PDF
  • 来源: 📄 arXiv 关键词检索
  • 核心方法: 针对 agentic RL 的信用分配。标准 GRPO 用最终 verifier 结果 $r_i=V(\tau_i)\in{0,1}$ 做组归一化优势 $A_i=(r_i-\bar r)/(\sigma_r+\epsilon)$，均匀分给轨迹里每个 token——结构性缺陷是：失败 rollout 里的有益探索被惩罚，成功 rollout 里的冗余/倒退动作被强化。TRIAGE 按动作角色分型（搜索、点击、编辑、导航等 environment-facing action）做差异化信用分配。
  • 对比方法/Baselines: 直接对标 GRPO，在 WebShop、QA 等 agentic 环境上评估。
  • 借鉴意义: GRPO 的 uniform advantage 是当前 agentic RL 训练最被诟病的点，角色分型信用分配是很自然但少人系统做的方向。做 agent 训练/RLHF 的必读。
  • 锐评: 诊断一针见血：uniform advantage 在长程 agent 轨迹里就是灾难，好探索被埋、坏动作被夸。角色分型（role-typed）的切入点比那些堆 reward model 的方案干净。隐忧是「动作角色」怎么自动划分、跨环境泛化如何——如果需要人工定义每类动作的 credit 规则，那实用性就打折。LinkedIn+Harvard+JHU 的组合，工程味应该够。🔥

  • 核心方法: ECHO 解决长程 agent 在有限上下文窗口下的两难：截断远期历史 / 折叠成摘要 / 选紧凑记忆状态，都会丢信息且跨 episode 经验流失。它用「剪枝来行动，trace 来学习」的选择性 turn memory——行动时用剪枝后的紧凑上下文，学习时保留完整 trace 供信用回溯，配合 SUPO/GRPO 在 BrowseComp 等基准上训练。
