1. Joint Optimization of Tool Creation and Use for Large Language Model Agents

  • 作者: Zhi Rui Tam, Chieh-Yen Lin, Yun-Nung Chen, Shao-Hua Sun, Hung-yi Lee
  • 机构: Affiliation:, Affiliation: National Taiwan University
  • 链接: arXiv | PDF

  • 来源: 📄 arXiv 关键词检索

  • 核心方法: SMITH 是一个多任务 RL 框架，把 tool creation（build）和 tool use（use）塞进同一个共享策略里联合训练。build 任务奖励 schema 正确性和执行准确率，use 任务只给 schema、奖励答案正确。关键在于：写工具的模型就是用工具的模型，所以模糊或损坏的 schema 会被直接惩罚——形成一个 prompting-only 方法给不了的反馈闭环。

  • 对比方法/Baselines: 对比 TroVE、LATM 等推理时 prompt 冻结 LLM 造工具的方法，以及 TabMWP/GQA 上的 tool-augmented baseline。
  • 借鉴意义: 对做 agent/function calling 的人是真命题：现有工具创造系统都是「让冻结的 LLM 临时造工具」，造的人和用的人脱钩，根本没有信号告诉模型「你造的 schema 你自己能不能调」。SMITH 把这条闭环补上了。
  • 锐评: 少见的抓到了真痛点的工作——「造工具的模型≠用工具的模型」这个 decoupling 确实是现有 tool-creation 的原罪，用一个共享策略 + 双任务奖励把它闭环掉，动机干净。存疑点：build/use 两个奖励的量纲和梯度冲突怎么平衡摘要没说清，多任务 RL 最容易翻车的就是这里；另外工具库规模一大，schema 空间爆炸时这套自洽性约束还撑不撑得住，是个悬念。但方向对。🔥

2. From State to Action: OODA-Tool for Reliable Multi-Turn Tool Use

  • 作者: Rongfeng Guo, Yinxuan Huang, Yusen Wu, Maoqing Zhong, Yunlu Chen, Meng Tang, Teng Long, Vincent Tao Hu\corresponding
  • 机构: Vincent Tao Hu
  • 链接: arXiv | PDF
  • 来源: 📄 arXiv 关键词检索
  • 核心方法: OODA-Tool 针对多轮工具使用中的状态-动作竞争问题：ReAct 式和直接 function-calling 策略把状态跟踪和动作生成学在同一条自回归轨迹里，生成下一个调用的压力会覆盖或忽略早期累积的信息。它引入一个 typed decision process（OODA：观察-判断-决策-行动），做 stage supervision 和 state-sufficiency 分析。
  • 对比方法/Baselines: 对比 ReAct、直接 function-calling，在 ToolDial、BFCL 上评测，用 LoRA 微调。
  • 借鉴意义: 多轮 agent 的老大难：状态漂移。把「记住任务状态」和「生成下一步动作」解耦是合理的架构选择，对做长程 tool-use agent 有参考价值。
  • 锐评: 诊断准——ReAct 把 state tracking 和 action generation 挤在一条轨迹里，确实会互相踩踏。用 typed decision process 显式分离是对症的。但 OODA 这个军事框架套上来有点为了讲故事而讲故事的嫌疑，四阶段划分是否真的对应到可监督的信号，还是只是给 prompt 加了几个标签，得看正文。state-sufficiency 分析是亮点，如果做扎实就是真东西。👀

3. SPO++: Stream-Aligned Policy Optimization for Asynchronous Agentic RL

  • 作者: Kai Ruan, Jinghao Lin, Qianshan Wei, Ziqi Zhou, Zihe Huang
  • 机构: Affiliation: , Affiliation: Duke University, Affiliation: Institute of Automation, Chinese Academy of Sciences, Affiliation: Gaoling School of Artificial Intelligence, Renmin University of China, Affiliation: Institute of Computing Technology, Chinese Academy of Sciences†Equal contribution
  • 链接: arXiv | PDF

  • 来源: 📄 arXiv 关键词检索

  • 核心方法: SPO++ 针对 group-relative RL（如 GRPO）必须等同一 prompt 的 sibling rollouts 才能算优势、对长且变长的工具调用轨迹极其昂贵的问题。它继承 SPO 的单流思路（用持久的 prompt 级价值估计去掉 group 依赖），但改进了 SPO「每条轨迹白化一个优势再优化 token-mean actor loss」的配方：请求在派发时读取并冻结一个 prompt baseline，返回时把结果挂到生成它的策略事件上，标量优势在 action-token 测度下标准化。

  • 对比方法/Baselines: 对比 GRPO、PPO、SPO，用 Dual-Clip 等技巧。
  • 借鉴意义: 异步 agentic RL 的省钱关键。做 tool-use / 长轨迹 agent 训练的团队最头疼的就是 GRPO 那个「等齐一组 rollout」的同步屏障，SPO++ 直接把它拆了，工程价值明确。
  • 锐评: 问题选得准、动机硬核——长轨迹工具调用下 group-relative 的同步等待就是浪费 GPU，异步单流是正解。SPO++ 相比 SPO 的改动（冻结 prompt baseline + action-token 测度标准化）看着很细，属于「魔鬼在细节」的调参级贡献，但这种细节恰恰是 RL 稳不稳的分水岭。担心的是：去掉 group 归一化后方差控制靠 persistent value estimate，这个估计一旦偏了整条流就跑偏。需要看它在 variance 上的实证。🔥

4. AHEAD: Adaptive Hindsight with Environment-Augmented Distillation for Agentic RL

  • 作者: Xiaolong Jin, Dingmin Wang, Vijay Lingam, Varun Kumar
  • 机构: Affiliation: , ††thanks: Work done during an internship at Amazon, Affiliation: Purdue University
  • 链接: arXiv | PDF
  • 来源: 📄 arXiv 关键词检索
  • 核心方法: AHEAD 做多轮 agent 的 step 级信用分配。三阶段：Stage 1 用 LLM analyzer 在失败轨迹里定位错误步；Stage 2 构造 step-aware 特权信息（常规步给环境反馈，错误步给环境反馈 + LLM 纠正提示）；Stage 3 通过比较策略在原始上下文和 PI 增强上下文下的 log 概率算 token 级自蒸馏信号，转成对 GRPO 优势的有界重加权。
  • 对比方法/Baselines: 对比轨迹级奖励的 GRPO、常规自蒸馏方法，在 WebShop 等环境评测。
  • 借鉴意义: 轨迹级奖励给每步一样的优势，根本不知道哪步导致成败——这是 multi-turn agent RL 的核心缺陷。AHEAD 用 hindsight + 特权信息补细粒度监督，方向正确。
  • 锐评: 思路扎实：用 privileged information（含 LLM 纠正提示）做 hindsight，再用 log-prob 差做 token 级自蒸馏重加权，比单纯的轨迹级 reward 细多了。但套路上是 AHEAD=错误定位 + PI 蒸馏 + GRPO 重加权的三段拼装，每一段都是已有零件。真正的风险在 Stage 1：用 LLM 定位错误步，这个 analyzer 本身多准？如果归因噪声大，后面两阶段都在放大噪声。👀

5. FARCA: Fact-Aligned Reliability-Aware Credit Assignment for Reinforcement Learning with Factual Supervision

  • 作者: Qiming Xie, Wenjie Zheng, Xiangqing Shen, Rui Xia\corresponding
  • 机构: Qiming Xie1 ,Anonymous, Wenjie Zheng1submission, hallucination risk, risk caused
  • 链接: arXiv | PDF
  • 来源: 📄 arXiv 关键词检索
  • 核心方法: FARCA（Fact-Aligned Reliability-Aware Credit Assignment）针对 RLVR 中 outcome-driven 奖励只看最终答案对错、不验证中间推理步事实性带来的幻觉风险。现有方案引入 process-level 事实监督，但因为事实信号粗粒度聚合、且缺乏对信号本身的可靠性评估，造成事实验证与策略更新的错配。FARCA 做细粒度对齐 + 可靠性感知的信用分配。
  • 对比方法/Baselines: 对比 GRPO、outcome-driven RLVR，在 TruthfulQA、HalluQA 上评测。
  • 借鉴意义: RLVR 只奖励最终答案对，中间可以一路胡编——这是 reasoning 模型幻觉的结构性来源。给中间步骤加可靠性感知的事实信用分配，对做 factual reasoning 的有价值。
  • 锐评: 问题真实：outcome reward 确实会纵容「结论对但过程瞎编」。FARCA 指出现有 process 监督的两个毛病（粗粒度聚合 + 不评估信号可靠性）算是有洞察。但「reliability-aware」这个词很容易变成又一层启发式加权，关键看它怎么量化「这个事实信号有多可信」——如果这个可靠性本身又是个 LLM 打分，那就是幻觉治幻觉，套娃。⚠️
