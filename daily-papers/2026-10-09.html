🔪 今日锐评

今天没有 arXiv 新鲜血液（被 429 限流），HF trending 把一堆『经典重播』和 2026 下半年的技术报告混着端上来：vLLM、Mem0、Zep 这些是老面孔，AgentScope 1.0、Apodex 1.1、SkillOpt 才是真正值得看的 agentic 新东西。整体主题高度集中在『agent 工程化』——框架、记忆、自进化、世界模型，推荐/广告领域今天颗粒无收。另：数据管线富化环节有污染，TradingAgents 的作者被填成了物理学家天团，大家看乐子即可。

2. Apodex 1.1: Scaling Agentic Intelligence for Complex Work

  • 作者: Apodex Team
  • 机构: Apodex 1.1: Scaling Agentic Intelligence for Complex Work
  • 链接: arXiv | PDF
  • 来源: 🔥 HF Trending，⬆️ 212
  • 核心方法: Apodex 1.1 提出 'working capability'（持续、可验证地朝真实目标推进）这一能力维度，核心主张是：除了扩 param/data/compute，还应该 scaling『agent 学习所处的可执行环境』——环境决定了 agent 能观察什么状态、能采取什么动作、如何验证完成。用 ReAct + RL 在 AgentOS 环境里训练。
  • 对比方法/Baselines: 对比 GPT-5、DeepSeek、OpenAI 系基线在复杂长程任务上的表现。
  • 借鉴意义: 『把环境当成第四个 scaling 维度』这个 framing 对做 agent RL 的人有启发——与其堆模型，不如堆高保真可验证环境。
  • 锐评: framing 很漂亮，TRACES 框架图也画得像模像样。但这是一份 team 技术报告（作者署名就是『Apodex Team』），缺乏可复现细节，『environment as a scaling surface』到底怎么量化 scaling law 没讲清。观点值得偷，结论别全信。👀

4. ARIS: Autonomous Research via Adversarial Multi-Agent Collaboration

  • 作者: Ruofeng Yang, Yongcan Li, Shuai Li
  • 机构: Affiliation: Shanghai Innovation Institute, Affiliation: Shanghai Jiao Tong University, Email: {wanshuiyin, joseph_y, shuaili8}@sjtu.edu.cn†Project Leader*Corresponding AuthorProject page: https://github.com/wanshuiyin/Auto-claude-code-research-in-sleep, Affiliation: , Email: 
  • 链接: arXiv | PDF

  • 来源: 🔥 HF Trending，⬆️ 155

  • 核心方法: ARIS（Auto-Research-in-sleep）是开源自主研究 harness，强调 agent 系统性能同时取决于模型权重和外围 harness。核心贡献是三阶段审计流水线应对 executor agent 产出误导性结果（自造引用、自归一化指标、无支撑声称）：Stage1 审计评估完整性、Stage2 把结果映射到显式声称、Stage3 用独立 reviewer 对照原始证据核验稿件声称。

  • 对比方法/Baselines: 基于 OpenHands、GPT-5、MCP 构建。
  • 借鉴意义: 自主科研 agent 的『防自欺』机制很有现实意义——LLM 做研究最大的风险就是编造实验结果，这套审计流水线直指该痛点。
  • 锐评: 上交/上海创智出品，直面了自主研究 agent 最尴尬的问题：agent 会给自己编造好看的实验结果。三阶段审计（尤其 Stage3 独立核验原始证据）是正确的工程方向。但 harness 类工作的有效性全看那个『独立 reviewer』本身可不可靠——用 LLM 审 LLM，谁来审 reviewer？开源这点加分。👀

5. SkillOpt: Executive Strategy for Self-Evolving Agent Skills

  • 作者: Yang, Yifan, Gong, Ziyang, Huang, Weiquan, Yang, Qihao, Zhou, Ziwei, Huang, Zisu, Li, Yan, Gao, Xuemei, Dai, Qi, Liu, Bei, Qiu, Kai, Yang, Yuqing, Chen, Dongdong, Yang, Xue, Luo, Chong
  • 机构: Fudan University, Microsoft, Shanghai Jiao Tong University, Tongji University
  • 链接: arXiv | PDF

  • 来源: 🔥 HF Trending，⬆️ 267

  • 核心方法: SkillOpt（EvoSkill）把 agent skill 当作『冻结 agent 的外部状态』来优化，像权重空间优化那样讲究可复现：用 executive strategy 控制 skill 的演化方向，而非 one-shot 生成或松散的 self-revision。借鉴 GEPA 的 trajectory feedback 和 TextGrad 的梯度式 prompt 优化思路。

  • 对比方法/Baselines: 对比 GEPA、TextGrad、ABSTRAL、EvoTest 等 prompt/配置自动调优方法；在 SpreadsheetBench、SearchQA、LiveMath 上评测。
  • 借鉴意义: 『skill 即可训练的外部状态』这个类比把 agent 自进化从玄学拉回到优化器纪律上，对想做无梯度 agent 改进的人非常对味。
  • 锐评: 今天最有思想的一篇。把 DL optimizer 的『可复现、单调改进』标准搬到 skill 演化上，直击当前 self-evolving agent『改一下好一下、再改又崩』的痛点。复旦+微软+上交的组合，benchmark 覆盖也够宽。唯一要盯的是：所谓『像优化器一样可靠改进』是否真扛得住跨任务泛化，别又是只在 benchmark 上成立。🔥

6. From Traces to Agentic Worlds: Agentic Language World Models for Interactive Environment Simulation

  • 作者: Quanyu Long, Xiao Chen, Jianda Chen, Haozhen Zhang, Qisheng Hu, Jianzhu Bao, Wenya Wang
  • 机构: Affiliation:, Affiliation: Nanyang Technological University, Affiliation: The Hong Kong Polytechnic University
  • 链接: arXiv | PDF
  • 来源: 📰 HF Daily，⬆️ 70
  • 核心方法: Trace2Env 提出 agentic language world modeling：不去重建可执行环境，而是让一个 world model agent 直接『扮演』环境，为 task agent 提供忠实、有状态（stateful）的模拟。用 EnvScaler 跨环境扩展，AgentWorldBench 评测。
  • 对比方法/Baselines: 对比 RAG 式检索和直接 GPT-5/DeepSeek 模拟；在 SWE 类 agentic 任务上验证。
  • 借鉴意义: 训练/评测 agent 时，真实系统常常不可访问或难复现——用 LLM 当环境可以绕过这个瓶颈，对做 agent RL 数据合成的人很有用。
  • 锐评: 思路和 Apodex『环境即 scaling 维度』遥相呼应，但更务实：既然搭真环境贵，那就让模型模拟。核心风险是 world model 的『忠实度』——模拟环境里训出来的 agent 到真环境会不会水土不服，论文得拿出 sim-to-real 的证据才算数。NTU + 港理工，值得追。👀

7. Mem0: Building Production-Ready AI Agents with Scalable Long-Term Memory

  • 作者: Prateek Chhikara, Dev Khant, Saket Aryan, Taranjeet Singh, and, research@mem0.ai
  • 机构: Affiliation:
  • 链接: arXiv | PDF
  • 来源: 🔥 HF Trending，⬆️ 73
  • 核心方法: Mem0 做 agent 长期记忆：通过专门的 extraction / update 模块，从多轮对话里动态抽取、巩固（consolidate）、检索关键信息，解决固定上下文窗口撑不住长会话的问题。Mem0g 变体用有向标注图存记忆（实体为节点、关系为边）。
  • 对比方法/Baselines: 对比 MemGPT、LangMem、普通 RAG；在 LOCOMO 长对话 benchmark 上评测。
  • 借鉴意义: 生产级 agent 记忆层的参考方案，extraction+consolidation 的工程拆分清晰，可直接对标自己的记忆模块设计。
  • 锐评: Mem0 是今年被引爆的记忆方案，工程完成度高、有现成服务。但学术上它更像是把『抽取-去重-检索』这套 RAG 老活儿针对对话场景打磨了一遍，novelty 有限。图记忆变体 Mem0g 更有看头。要落地记忆模块值得读，想看理论创新就算了。👀

8. Zep: A Temporal Knowledge Graph Architecture for Agent Memory

  • 作者: Preston Rasmussen, Pavlo Paliychuk, Travis Beauvais, Jack Ryan, Daniel Chalef
  • 机构: Email: , Affiliation: 
  • 链接: arXiv | PDF

  • 来源: 🔥 HF Trending，⬆️ 17

  • 核心方法: Zep 用时序感知的动态知识图谱 G=(N,E,φ) 做记忆层，分三层子图：episode 子图（原始事件）、semantic entity 子图（抽取的实体）、community 子图（社区聚类），显式建模时间维度。

  • 对比方法/Baselines: 超越 MemGPT，在 DMR 和更贴近企业场景的 LongMemEval 上评测。
  • 借鉴意义: 和 Mem0 并列的另一条记忆路线——重结构化时序知识图谱。做需要时间推理（『上周说过的事』）的 agent 可参考。
  • 锐评: 和 Mem0 正好是记忆的两种哲学：Mem0 偏轻量 consolidation，Zep 押重结构化时序 KG。三层子图设计优雅，时间维度建模是真需求。代价是 KG 构建和维护的工程开销——企业场景扛得住，个人 agent 可能过重。两篇对着读收获最大。👀

14. MARGIN: Runtime Confidence Calibration for Multi-Agent Foundation Model Coordination

  • 作者: Joss Armstrong
  • 机构: Email: , Affiliation: 
  • 链接: arXiv | PDF

  • 来源: 📰 HF Daily，⬆️ 0

  • 核心方法: MARGIN 做多 agent 运行时置信度校准：当协调者比较异构基础模型的答案时，各模型的 self-reported confidence 含义不一致，MARGIN 通过增量归一化（incremental normalisation）从观测到的答案结果中学习模型特定的置信度修正，无需重训或 held-out 校准集。
